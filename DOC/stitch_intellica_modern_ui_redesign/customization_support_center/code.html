Knowledge Base

How do I bulk-approve faculty credits? expand_more
To bulk approve, navigate to the "Credit Approval" screen, select multiple entries using the checkboxes in the data table, and click the "Batch Action" button in the header toolbar.
Can I customize the evidence requirement forms? expand_more
Yes, super-admins can modify requirement schemas via the "Settings > Form Builder" section. Changes will apply to all future submissions.
What file formats are supported for PDF ingestion? expand_more
We support PDF, DOCX, and high-resolution JPEG/PNG. For automated OCR processing, we recommend 300DPI PDF files.
